# Обслуживание сервера

## Обновление

`tendvpn update` сначала сохраняет базу и конфигурацию, затем применяет версии
Docker-образов из установленного кода и проверяет работу сервисов.
На `latest` команда не переключается.

Для обновления самого установщика повтори команду установки из нового релиза.
После этого запусти `tendvpn update`.

Compose, NGINX и env-файлы генерируются заново при обновлении. Ручные изменения
этих файлов будут заменены. Если нужен свой вариант конфигурации, меняй генератор
в исходниках или веди собственный fork.

Автоматического отката миграций PostgreSQL пока нет.

## Резервная копия

```sh
tendvpn backup
```

Копия появится в `/opt/tendvpn/backups/<UTC timestamp>/`. В ней находятся
PostgreSQL dump, состояние установщика, Compose, конфигурация NGINX и env-файлы.
Сертификаты в копию не входят: на новом сервере их нужно выпустить заново.

Копия содержит пароли и ключи. Сохраняй её в закрытом хранилище и периодически
переноси с VPS: файлы на том же диске не помогут при потере сервера.
Восстановление из меню пока не реализовано.

## Сертификаты

Продление выполняется автоматически через webroot и systemd-таймер.
Порт 80 должен оставаться доступным извне для проверки Let's Encrypt.

```sh
tendvpn renew
systemctl list-timers tendvpn-cert-renew.timer
```

`renew` проверяет срок сертификата. Если продление ещё не требуется, действующий
сертификат остаётся на месте.

## Удаление

```sh
tendvpn remove
```

После ввода `УДАЛИТЬ` скрипт делает копию, отключает свой таймер и удаляет контейнеры
и Docker-сеть проекта. База в Docker volume, настройки и сертификаты сохраняются.
Чтобы снова запустить эту установку, выполни `tendvpn install`.
Полного удаления данных через меню пока нет.

## Если установка прервалась

Запусти `tendvpn install`. Домены, ключи и созданные объекты сохраняются между
попытками. При ожидании APT мастер ждёт освобождения блокировки до 10 минут.
Уже установленные зависимости при продолжении пропускаются.

Для диагностики:

```sh
tendvpn status
tendvpn diagnose
```

Логи могут содержать адреса подписок и другие чувствительные данные.
Перед отправкой в issue убери их.
