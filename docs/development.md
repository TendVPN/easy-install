# Разработка и проверка

Для локальных проверок нужны Python 3 и Docker Compose. Запуск Docker-сервисов
и root для этих команд не требуется.

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
sh -n install.sh tendvpn
./tendvpn plan --output .preview
docker compose --project-directory .preview -f .preview/compose.json config --quiet
```

`plan` создаёт preview с тестовыми секретами. Он не устанавливает пакеты,
не запускает контейнеры и не меняет настройки системы. Рабочую установку
из этого preview запускать не нужно.

16 тестов проверяют создание и связывание объектов через симулятор API,
продолжение после потерянного POST-ответа, отсутствие дублей, сохранение ключей,
ошибки API, требования к паролю, порты, сокет, права файлов и формат подписки.
В GitHub Actions дополнительно проверяется конфигурация Compose.

## Запуск локального кода на VPS

Скопируй весь каталог проекта на отдельный VPS с Ubuntu 24.04:

```sh
sudo sh ./install.sh --local
```

Дальше используй меню. Подробный порядок проверки — в [VPS-TEST.md](VPS-TEST.md).

## Перед релизом

Первый интеграционный прогон выполнен на Ubuntu 24.04 amd64 17 ноября 2026 года.
Во время установки обнаружены и исправлены ошибки старта API, генерации пароля
и обработки числового ID пользователя. После исправлений проверены повторная
установка, обновление, удаление контейнеров с сохранением данных и перезагрузка.
Внешний Xray-клиент подтвердил рабочий трафик и ожидаемый выходной IP.

Полный чистый прогон итоговой версии после всех исправлений пока не повторялся.
Нативный импорт в Happ и arm64 требуют отдельной проверки.

Для туториала удобно закрепить bootstrap и скачиваемый архив на одном теге:

```sh
curl -fsSL https://raw.githubusercontent.com/TendVPN/easy-install/<TAG>/install.sh \
  | TENDVPN_REF=<TAG> sh
```

Замени `<TAG>` существующим тегом проверенного релиза. Так изменения в `main`
не поменяют поведение команды из описания ролика.
